# R3 Meta-Capsule v3.1.0 — WAD-18

Executable companion to *Self-Application of the Russell Recursive Refinement
Operator*. Implements `R3 = lfp(Phi)`, `Phi = Proj . F . A`, entirely in
**WAD-18**: weak arithmetic decidability at 18 exact decimal digits.

    sh run.sh                        # full pipeline, about a minute
    MUTATION=exhaustive sh run.sh    # adds the full mutation run, ~15 min

Python 3.8+ and nothing else. No pip install, no network, no third-party
packages. 131 tests under `unittest`.

## What changed in v3, and why

**PO3's "honest negative" in v2 was a search defect, not a finding.** v2
reported that no design dominates the reference and presented that as an
honest negative result. It was wrong: the anchor *is* dominated, for instance
by `(12,27,6,21,18,18)`. The scalarised search could not reach dominators
because its weights point elsewhere, and reporting a weighted descent's
failure as evidence that no dominating design exists is precisely the class of
error this whole document is about. PO3 is now judged against a non-dominated
archive, which contains 12 witnesses. The scalarised optimum's failure to
dominate is still reported, next to the explanation.

**Every equivalence judgement was eliminated by changing the code, not by
arguing.** v2 classified 8 survivors as equivalent on my own say-so, and I
flagged that as the weakest thing in the capsule. The constructs that generated
them are gone:

* five `sort_keys=True` literals collapsed into one `canon` and one `render`
* `(x4 + x5) % 2` replaced by a predicate on the coordinates — sum-parity
  equals difference-parity, so every `+`/`-` mutation there was an equivalence
  by construction
* the G3 repair is branch-free: `need = max(0, gmin - gap)` instead of a
  comparison that was a no-op when the gap already cleared
* a dead `i = 1 - i`, a dead at-the-cap loop exit, and a dead percentile clamp
  removed outright

**The admitted gap is closed.** `domain.py@93` is gone: escaping the upper
bound is now structurally impossible via `min(HI, ...)` rather than prevented
by a comparison that has to be got right.

**Mutation is exhaustive, not sampled.** A sampled rate moves between runs and
is not a score. `run.sh` defaults to a fast sample written to its own file so
it cannot overwrite the recorded exhaustive result.

**A false-survivor bug in the harness itself.** Mutants are written in place,
and CPython validates a cached `.pyc` by `(mtime, size)`. A mutation that does
not change the file size, written inside one mtime tick, was served from a
stale cache: the mutant never loaded, the suite passed, and it was recorded as
a survivor. The harness was *understating* its own tests. Fixed with
`PYTHONDONTWRITEBYTECODE` and a cache clear per mutant.

**PO6 is machine-checkable now.** `src/ratify.py` verifies a detached
attestation that binds to the SHA3 of the invariant file. Editing the
invariants afterwards returns `REVOKED_BY_EDIT` automatically — you cannot
ratify a set and then quietly change it.

## WAD-18

A value is a Python int `n` denoting `n / 10**18`. Python ints are arbitrary
precision, so nothing is truncated to a machine word.

* Primitives are `+`, `-`, `*` and division by a non-zero integer — the
  operations of the ordered ring of integers. Comparison is exact.
* No transcendental is a primitive. Where one was needed it was eliminated,
  not approximated.
* Rounding declared once: half-even for `mul` and `div`, floor for `sqrt` with
  the residual exposed by `sqrt_exact`. Truncation is rejected as biased, and
  a biased mode drifts over an iteration whose termination argument depends on
  a monotone measure.
* Enforced, not promised: `src/determinism.py` parses every file in `src/` and
  rejects float literals, `float()`, the `/` operator, any `math.*` call other
  than `isqrt`, and imports of `random`, `statistics`, `decimal`, `fractions`
  or `numpy`. `run.sh` fails closed.

D1 of the old determinism contract is vacuous: there is no floating point left
to pin. D6 replaces it.

### The constraint improved the statistics

The Wilcoxon test used a normal approximation, which needs `erf`, which WAD-18
does not have. The replacement enumerates the null distribution exactly by
integer DP over subset sums of the doubled signed ranks.

| | p |
|---|---|
| normal approximation (v1) | 0.0000018185 |
| exact DP (v2, v3) | 1/536870912 = 0.000000001862645149 |

Ranks are carried doubled so mid-ranks from ties stay integral.

## The domain instance

Six 6-bit integers. The feasible set is deliberately **non-convex**
(`x0*x1 >= 300`) and **disconnected** (`|x2-x3| >= 10`), so the metric
existence route is genuinely unavailable and the termination route must be
used. Dynamic range is bounded and known a priori, which is the regime in
which integer arithmetic is the right choice rather than a superstition.

PO5 finding: of the three constraint parameters perturbed by +/-10%,
`P_SUM_MAX` carries essentially all the output variance (S1 = 0.990, CI
containing 1); the product and gap constraints are inactive at the optimum
(S1 ~ 0, CIs containing 0).

## What this capsule still does NOT establish

0. **A perfect in-scope score is not a certificate.** 7/7 says the artefact
   did everything it could be asked to do here. It says nothing about whether
   the asking was right, and the next point is why.
1. **The certificate is vacuous.** `spec/meta_invariants.json` has
   `externally_frozen: false`. The invariants were authored by the same agent
   that runs Phi, after the defects were already observed. By Proposition 4,
   self-certification against a self-authored set establishes nothing.
   `logs/result.json` says so in its own field. A 100% effective mutation
   score does not change this and is not evidence against it.
2. **PO6 is open** for the same reason, and no code change closes it.
3. **The contribution claim is scoped** to a penalty hill-climb baseline on one
   instance. It is not a claim against modern constrained optimisers.
